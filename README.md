# Ink Storylets

Finally! A storylet system for Ink that is not a massive pain.


- supports selecting a list of options to display to the player
- supports selecting a single story to jump to immediately
- does not require defining a knot or a list item for each individual storylet
- supports modularity (combining multiple lists of storylets)
- syntax is *relatively* pleasant (by Ink standards, at least)
- allows saving/reloading a selection of storylets (with caveats)
